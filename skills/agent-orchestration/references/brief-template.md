# Brief template

```
GOAL: <one sentence outcome>
CONTEXT / KNOWN FACTS: <paths, findings, decisions made; do not re-derive>
CONSTRAINTS: <read AGENTS.md/CLAUDE.md first; do not touch X; no new deps; ...>
VERIFICATION: <test-first: failing evidence, then passing; exact commands>
REPORT (short): what changed · evidence (command + result) · open risks · commit/PR
IF BLOCKED: report the blocker; do not guess destructive actions.
```
Tips: one outcome per child; give the diff/files, not your theory, to reviewers; when resending after a quota switch, include partial work done so far. Wait in a single blocking command rather than ending the turn.
